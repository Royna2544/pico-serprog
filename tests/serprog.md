# Serprog SPI-only behavior

Protocol reference: https://flashrom.org/supported_hw/supported_prog/serprog/serprog-protocol.html (version 1).

- The command map advertises NOP, Q_IFACE, Q_CMDMAP, Q_PGMNAME, Q_SERBUF, Q_BUSTYPE, Q_WRNMAXLEN, SYNCNOP, Q_RDNMAXLEN, S_BUSTYPE, O_SPIOP, S_SPI_FREQ. Address-oriented `R_BYTE`, `R_NBYTES`, `O_INIT`, `O_WRITEB`, `O_WRITEN`, `O_DELAY`, `O_EXEC` and `Q_OPBUF` are not offered; known parameter lengths are consumed before NAK to keep the serial stream aligned. No NOR-specific read/program translation is attempted.
- `Q_WRNMAXLEN` and `Q_RDNMAXLEN` each report 4096 bytes; larger `O_SPIOP` payloads are consumed and NAKed, not executed. One successful SPI operation returns precisely one ACK followed by exactly `rlen` bytes. The implementation buffers up to 4096 received bytes before ACK to allow SPI errors to return NAK instead of a partial successful frame. `Q_SERBUF` remains 64 bytes.
- The complete bounded send payload is received before CS assertion; an incomplete host frame cannot hold the flash selected while CDC waits. `tests/test-serprog-cs-order.c` exercises the production command handler and its CS/read ordering.
- `S_SPI_FREQ` rejects zero, sets the SPI master and reports the frequency read back from that master (which may be rounded by the controller). The Pico SPI chip driver **already** switches to the chip node's `default-baud` on each CS assertion and restores the prior master baud on deassertion. Accordingly, the reported `S_SPI_FREQ` master setting is truthful at the time of the reply but does **not** persist as the clock used while that chip is selected. This is the explicitly chosen per-chip policy, not a claim of sustained negotiated transfer frequency. The fake NOR SPI model's CS callbacks do not emulate this Pico chip clock switching, so host CDC1 tests verify the reply, not the electrical clock at CS.
- The existing host PTY shim and `tests/test-serprog-host.py` exercise the real CMake host binary with ASan/UBSan. No physical RP2040/SPI signal timing or USB device is exercised.
